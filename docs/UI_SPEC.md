# UI specification — awaiting designer
Direction: calm editorial design, readable typography, restrained blue/teal accents,
generous spacing and high-contrast data displays.
Public pages: home, tools index, four tool pages, guides index, guide detail, methodology,
About, Contact, Privacy, Terms and editorial/corrections.
Workspace: input/editor, visual result, accessible table, assumptions, examples, save/export and reset.
Specify desktop/mobile layouts, navigation, keyboard/focus behavior, chart alternatives,
empty/loading/error states, impossible plans, validation, unsaved changes and export feedback.
Target WCAG 2.2 AA; record manual checks as well as automated results.
Ad placements, when enabled, must be separated from tool controls and cannot obscure content.
Private workspace/auth/error/empty states receive no ads.
Designer approves page specifications before frontend implementation.
